## Scope and maintenance

These records describe the current state of the fork and the evidence available for it. Roadmap items are proposals or pending work unless explicitly marked complete; a build or automated test alone does not establish that a live-game workflow has been validated.

Use relative links for files within this repository. When moving a document, update links that point to it and check the rendered result on GitHub. Keep historical reports separate from current setup instructions so old observations are not mistaken for current support guarantees.
